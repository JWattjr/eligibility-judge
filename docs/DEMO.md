# Two-minute demonstration

**0:00–0:20 — Public ledger.** Open the app without a wallet. Introduce Eligibility Judge: every entry gets a rule-by-rule verdict anyone can verify. This qualifies entries; it never ranks them. Check the status and the Recorded proof label before describing results. If completion is false, explicitly say the live proof is incomplete.

**0:20–0:45 — Frozen rulebook.** Choose Rulebook. Read the four checkable rules and the frozen hash. Explain that each rule was validated in its own GenLayer transaction. Open one of the rule-validation receipt links in Public proof trail.

**0:45–1:10 — Evidence, not scores.** Return to Entries. Open a pass chip on the qualified entry, then a failing chip on the disqualified entry. Show the exact quote and file link at its pinned commit. Open the insufficient-evidence entry and explain the nonexistent SHA. If the injection fixture is present, show its clear label and its failing Python-contract rule.

**1:10–1:30 — Finality.** Switch to Live chain. This reads `LATEST_FINAL`, never an accepted result masquerading as final. Explain the resumable transaction trail and native appeal availability. Wallet signatures are needed only to write, not to audit.

**1:30–1:50 — Equal pool.** Choose Payouts. Show the equal split and organizer remainder. Follow the settlement and qualifier-claim links. A credited native transfer is the payout proof, not merely a successful claim request.

**1:50–2:00 — Build and verify.** Show the public repository and `npm run verify:proof`. Finish with the architecture, test coverage, and the development-network limitation. The owner submits the Portal fields manually.
